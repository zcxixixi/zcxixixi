## Current Focus

I am building and studying **harnessed agentic workflows**: systems that turn an ill-structured question into explicit assumptions, validated intermediate artifacts, bounded simulation runs, provenance traces, and evidence-linked final claims.

The core problem I care about is simple: an AI agent should not only produce an answer. It should expose what it assumed, what evidence it used, where the intermediate state changed, and why the final claim is inspectable.

## Selected Work

### Harnessed Agentic Simulation for Controllable Decision Support

Research proposal and prototype direction for traceable portfolio scenario analysis under uncertainty.

- Converts a natural-language decision question into structured objects such as `DecisionSpec`, `WorldSpec`, `EvidenceCard`, `Assumption`, `TraceEvent`, and `ReportClaim`.
- Uses validation, repair loops, retrieval, simulation, and provenance tracing to keep long-running agent workflows auditable.
- Evaluates the workflow against prompt-only and single-agent baselines using validity, unsupported-claim rate, trace coverage, and runtime overhead.
- Prototype direction: [traceable-agentic-simulation-demo](https://github.com/zcxixixi/traceable-agentic-simulation-demo)

### Friction-Aware Cooperative ADRC-NN Control for Multi-DOF Manipulators

Control research project combining ADRC, neural-network compensation, and simulation-based validation.

- Designed a cooperative ADRC and neural-network strategy for nonlinear friction disturbance compensation.
- Implemented an ESO-NN control architecture in MATLAB / Simulink / Python.
- Compared against PID and pure ADRC baselines for tracking accuracy, robustness, and low-speed friction behavior.

### HKUDS nanobot Open-Source Contributions

Open-source work on a lightweight AI-agent framework from HKU Data Intelligence Laboratory.

- Contributed PRs around external communication capability, CLI reliability, CJK text workflows, and command-handling logic.
- Worked with Python, CLI design, IMAP / SMTP integration, and user-agent interaction flow.
- Project: [HKUDS/nanobot](https://github.com/HKUDS/nanobot)

### Embedded Vision Measurement and Control System
